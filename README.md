# Homebrew Tap for HealthyVibe

HealthyVibe / Vibe 延寿指南的 Homebrew Cask 仓库。

## 安装

```bash
brew tap xfey/tap
brew install --cask healthyvibe
```

也可以使用一行命令：

```bash
brew install --cask xfey/tap/healthyvibe
```

## 卸载

```bash
brew uninstall --cask healthyvibe
```

如需同时清理本地数据：

```bash
brew uninstall --cask --zap healthyvibe
```

## Cask

当前 cask 文件：

```text
Casks/healthyvibe.rb
```

发布包来自：

```text
https://github.com/xfey/HealthyVibe/releases/download/v1.0.0/HealthyVibe-1.0.0.zip
```
